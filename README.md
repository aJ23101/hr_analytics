# 📊 HR Analytics Dashboard

An end-to-end HR Analytics project using **Python, PostgreSQL, SQL, and Power BI** to clean, analyze, and visualize employee data for actionable workforce insights.

## 🚀 Tech Stack

- Python (Pandas, NumPy)
- Matplotlib & Seaborn
- PostgreSQL
- SQL (Window Functions, CTEs)
- SQLAlchemy
- Power BI

---

## 📂 Project Structure

```
├── HRDataset_v14.csv                 # Raw dataset
├── HR_Employee_Cleaned_Data.csv      # Cleaned dataset
├── hr_data_analytics.ipynb           # Data cleaning & EDA
├── hr_analytics.sql                  # SQL analysis
├── hr_analytics_dashboard.pbix       # Power BI dashboard
└── README.md
```

---

## 📌 Project Workflow

- Cleaned and transformed raw HR data using **Pandas**
- Performed **Exploratory Data Analysis (EDA)** with Matplotlib & Seaborn
- Loaded cleaned data into **PostgreSQL** using SQLAlchemy
- Wrote SQL queries to analyze salaries, turnover, diversity, recruitment, and performance
- Built an interactive **Power BI Dashboard** for HR insights

---

## 📊 Dashboard Insights

- Employee Headcount
- Average Salary by Department
- Gender Pay Analysis
- Employee Turnover
- Performance vs Salary
- Recruitment Source Analysis
- Diversity Hiring
- Absenteeism Analysis

## ▶️ How to Run

1. Run `hr_data_analytics.ipynb`
2. Load the cleaned data into PostgreSQL
3. Execute `hr_analytics.sql`
4. Open `hr_analytics_dashboard.pbix` in Power BI Desktop
